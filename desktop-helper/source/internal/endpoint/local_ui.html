SJFX 本机助手

这里只管理这台电脑与资料的关联，分析工作仍在原网站完成。

正在读取本机状态…

1 · 绑定账号

在 SJFX 网站的“文件保护”页面生成绑定码，复制到这里。绑定码十分钟内有效，只能使用一次。



2 · 关联本地资料

先在网站上建立服务器文件清单，再将该清单的“关联编号”复制到这里。点击后会打开 Windows 文件夹选择框。



仅在所选目录内查找相同内容；不上传本地原文件。首次计算内容指纹可能需要一段时间。

同内容映射

同内容存在多个服务器成员时，填入明确映射再完整核验。格式为成员编号到本地相对路径。

提交选定的新版本待检查

正常编辑保留资料关系，并使旧核验失效。这里只上传明确选择的一个文件到服务器待检查区，单文件上限 64 MiB。提交后仍需内容检查和完整核验。



运行状态

仅采集所选目录变化及可用的 Windows 访问事件。句柄锁在助手退出时释放；删保护允许原位编辑，但可能阻止替换式保存。不保证阻止其他软件外发。
