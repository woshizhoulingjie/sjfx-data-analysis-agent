# 本地文件保护候选说明（2026-10-13）

这是可审阅、可复测的候选源码，未安装、未启用真实资料保护。既有生产服务和已安装助手未被替换。

## 实际读取位置

只读核实发现现有生产进程在 Linux `/home/nas511/zhoulingjie/sjfx` 打开路径，浏览器只提交路径文本，没有 Windows 内容桥。因此本候选选择“资料电脑上运行 SJFX”的实现：本机路径是唯一输入，本机 Python 核心、业务解析和可选 Windows 助手读取同一文件实例。Linux 上的 Windows 盘符请求返回 `reader_host_mismatch`，不会当成远端相对路径。

保持远端界面直接分析电脑文件需要另建经授权的字节传输桥，本候选未实现，也不要求用户二次手工上传。

## 运行与配置

1. 使用本候选源码和已有双平台启动器 `sjfxctl.py`，按 `platform-compatibility.md` 准备 Python 3.12、应用依赖及所选模型资源。使用新的 `SJFX_ENV_FILE`、`SJFX_STATE_DIR`、`SJFX_OUTPUT_DIR` 和可写临时目录；不要复用正在运行的生产状态。
2. `SCAN_ALLOWED_ROOTS` 明确列出本机资料根，状态/快照目录不能位于原始资料根内。业务账号授权与路径根限制同时生效。默认只允许实例上传目录，必须按实际用途配置本机资料根。
3. 在 `/protection` 登录管理员，设置资料包总开关、操作规则和授权根。新状态默认关闭。实际开关持久化在 `<state>/file_protection/package-policy.json`；旧环境变量 `SJFX_PROTECTION_MODE` 不替代该开关。
4. 默认必要引擎为静态检查和 ClamAV。配置实际扫描程序与数据库后再验收启用。必要引擎不存在、版本/数据库信息无效、扫描错误或超限均拒绝使用。测试中的 `required_engines=['static']` 是明确的有限覆盖测试配置，不是上线推荐，也不代表病毒扫描通过。
5. 若需 Windows 文件变化采集和固定目标处置，使用本交付 `agent/bin/sjfx-assistant-local-candidate-v2.exe` 的独立本机模式、独立 `--data` 目录和 `--local-token-file`。令牌为安全随机生成的 32 字节、64 位小写十六进制文本，仅当前 OS 账号/管理员可读；Python 环境的 `SJFX_LOCAL_AGENT_TOKEN_FILE` 指向同一文件。完整助手参数见交付目录 `agent/LOCAL_PROTECTION_CANDIDATE.md`。

核心和助手通过 `127.0.0.1:18766` 通信，令牌不传给浏览器，不使用代理或跳转；现有 18765 助手及其状态目录保持独立。候选服务一个隔离账号，拒绝把另一账号的注册覆盖到同一助手状态。源码包含旧协议历史模块和既有上传兼容入口；本地新流程无服务器副本匹配要求。

## 准入与版本

设备标识、Windows 卷/文件 ID、内容 SHA-256、资料包清单修订、策略修订和监控缺口代次共同限定每次决定。操作前重新验证实际成员；解析、预览等读取冻结的已核验快照。内容改变产生新版本，替换文件产生新实例，改名加修改保留可证明的逻辑关系。

HTTP、新分析、队列恢复、普通/大包/问答后台、模型调用、缓存摘要、搜索、翻译、邮件附件、预览和导出下载接入共同校验。旧任务和无来源缓存不会因新分析通过而自动被重新授权。多资料包审批按登记 ID 分别传递；敏感导出与下载统一为 export，翻译的 HTTP、后台任务和模型检查使用 translate。

总开关关闭时正常业务放行，但既有锁或隔离不会自动撤销。恢复仍走原处置记录、固定目标身份和结果回执；完成恢复再停止或移除候选助手。

## 覆盖与容量

- 静态规则覆盖邮件/活动 HTML/凭据表单/链接伪装、危险附件、执行内容伪装、Office 活动内容及压缩路径、体积与嵌套限制；规则没有命中只代表配置覆盖范围内没有检测结果。
- 单包助手完整登记上限为 1000 文件、1 MiB 请求和 8 GiB 稳定快照总量。超限不接受部分登记，返回 413 和 `local_agent_capacity_exceeded`。该包覆盖不足不会阻止其他包事件补报和已有处置恢复。
- 核心清单默认上限 20 万文件，不能据此声称 Windows 助手也覆盖同样规模。快照、快照树、暂存和派生内容共用默认 16 GiB 配额，保留期默认七天。回收只面向受控区域的过期、未引用数据，不删除业务输出或输入。
- 受控存储拒绝路径穿越、NTFS ADS、符号链接和目录联接，在读写与异常清理前复查。Python 路径复核不等同内核级原子防替换；状态和令牌目录必须由可信本机账号管理。拥有同等 OS 权限并可修改程序/状态的进程不在隔离承诺内。
- 助手离线、重启或缺口使旧覆盖证据失效；本机逐次字节核验并不证明 OS 访问日志完整。

## 验证边界

Windows 合成资料实际验证了本机认证登记/同步、相同实例版本、删除句柄锁、OFF 恢复、内容修改、离线重启、危险内容拒绝和履历联查。独立审计新增了竞态、无效 AV 回执、目录联接清理、后台 QA 缓存、审批继承等回归。

没有安装真实 ClamAV/YARA/rspamd，没有以管理员权限改变 Windows Security/SACL 策略，没有执行真实 GPU 模型整机推理验收。管理员 SACL 测试明确跳过。目录观察和 Security 日志是采集证据；特定目标锁和隔离不能被表述为所有第三方软件的事前过滤器。

测试数量、命令、最终二进制 SHA 和交付清单见工作目录最终验收报告。生产启用前须在目标机器补做真实引擎、审计权限、模型资源和应用启动验收。
