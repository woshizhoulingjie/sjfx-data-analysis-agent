# 摘要限定语保真：第十二轮工程化修复

日期：2026-09-27。基线：`8f1ce51e3c92fdaf1eba2ad00cf42e06981b856b`。

## 范围与行为

保留普通摘要“结论—支撑证据”结构和大包摘要既有标题。基于先前真实模型对合成验收材料的输出，处理两类窄范围错误：

- 原文未确认完成，不得断言已完成或尚未完成；识别到的错误状态改为“状态未获原文确认”。
- 原文未授权某操作，不得自动升级为明令禁止；仅在动作尾部一致且未出现明确禁止证据时修正。

接入普通预览、快速/批量摘要提示、正式文件结论构建，以及实际的大包深度摘要入口。更换提示版本时保留旧版本并把新版本加入节点调度白名单，避免文件摘要已完成但节点与概览无法继续。

`services/summary_fidelity.py` 为纯函数，不调用模型、不读写文件，不改原文或来源标识。记录原句、修正句、来源ID及输入/输出摘要。重复处理保留审计记录。正式结论构建时自动纠偏文本仍为待审核项，不因措辞变谨慎而自动升级为已验证；空白规范化不能绕过此限制。预览仍标记为候选支持，不能冒充全文验证。

## 保守边界

- 只支持有限语法，不是通用语义蕴含、时态推理或实体消歧引擎。
- 引号、假设、建议、转述等上下文不盲目改写；不确定结构留给既有校验和人工审核。
- 多文件、空来源、超过1000证据项或20万字符时显式标记未检查；不截断后半段以免忽略相反证据。
- 明确禁止、更新后的确定状态不能被早期不确定性覆盖。
- 仅补充保留原日期的生成指令，没有宣称解决所有历史计划和当前状态混淆。
- 大包深度摘要仍只覆盖采样正文，保留 `coverage=sampled` 及原有截断/降级语义。
