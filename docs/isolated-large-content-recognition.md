# 独立大数据包内容识别

此改动仅用于 `/api/large-packages`、`large_package.db` 和独立大包 Worker。普通导入、对话、关系分析、统一解析器和共享模型实现未改动。

## 用户流程

1. 盘点目录，批量保存文件信息；原始目录可在盘点过程中查看。
2. 按格式生成轻量内容画像：字段、章节或标题、代表性内容、主题候选、用途、明确的项目/参与者/时间线索，以及来源位置。
3. 使用业务主题、用途与有界字段/标题相似性增量分组。陌生主题保留原文字段或标题，不强行归入固定业务类别。
4. 对识别不足的文件追加一次有预算的采样/OCR；预算耗尽后立即开放选择，剩余项继续保留。
5. 在目录页点击“补充内容识别”继续处理未完成项。旧任务也通过这个按钮升级，不自动重写旧摘要。
6. 选择文件后使用现有深度解析与模型摘要流程。Word/JSON 导出仍可使用。

## 默认预算

| 项目 | 默认值 |
|---|---:|
| 基础读取字节预算（可直接计量的读取） | 64 KiB/文件 |
| 补充读取预算 | 基础预算的 3 倍 |
| 基础解析时间 | 4秒/文件，子进程启动额外容许1秒 |
| 补充解析时间 | 15秒/文件 |
| 解析子进程内存 | 1.5 GiB，超出后终止 |
| 一轮补充识别 | 最多60秒或30个文件 |
| 基础PDF代表页 | 最多3页 |
| 补充PDF代表页 | 最多6页，其中最多2页OCR |
| 单页OCR缩放 | 最长边约1600像素 |
| 解析子进程复用 | 每100个调用回收 |
| 相似分组候选比较 | 最多24组/文件 |
| 原始目录响应 | 最多500个节点，明确标记超限 |
| 主题响应 | 最多200组，完整文件保留并可检索 |
| 文件列表 | 每页100条，服务端过滤后分页 |

PDF内部对象读取与解压不承诺64KiB的物理I/O上限，使用独立子进程的时间和内存约束。Office预算约束读取的解压内容；ZIP中央目录另有已有预检。压缩文件/复杂格式不能随意从任意字节恢复语义。

## 可调环境变量

所有变量只在独立内容识别模块使用：

- `SJFX_LP_PREVIEW_BYTES`：8192–262144，默认65536。
- `SJFX_LP_PREVIEW_SECONDS`：1–30，默认4。
- `SJFX_LP_REFINE_SECONDS`：1–30，默认15。
- `SJFX_LP_RECOGNITION_SLICE_SECONDS`：5–300，默认60。
- `SJFX_LP_RECOGNITION_SLICE_FILES`：1–200，默认30。

OCR使用现有本地RapidOCR模型且限定CPU。不下载模型。内容识别不调用逐文件生成式模型，避免新增LLM等待和GPU争用。主题标签由可追溯标题/字段/业务线索生成；相似分组依据明确标注，不把同模板或同名称认定为同一事项。

## 覆盖与兼容

- 样本哈希独立保存；完整源文件SHA-256在深度解析时计算和保存。二者不混淆。
- 所有画像标记为预览，保存采样位置、时间/字节预算和待核查状态。
- 普通导入数据库不参与迁移。大包数据库仅新增列、索引和画像分组/维度表。
- 快速队列、深度队列、选中文件与旧深度摘要保留。
- 补充超时不会覆盖已有有效画像；失败重试保留队列，暂停会释放轻量解析子进程。
- 一轮补充按稳定散列顺序选择并优先处理未尝试项，避免大目录排列导致同类文件垄断预算。
- 同一数据包的任务选择需在当前阶段完成后提交，防止覆盖正在运行的阶段。
- 深度解析返回元数据、没有正文和证据时，不再将该文件计为深度成功。

## 已知边界

首轮不是全文解析。Office目前读取有界正文/工作表内容；不能承诺覆盖每一章节、每个工作表。CSV有引号时不把随机窗口当作可靠的多行记录。未知旧二进制格式会标记暂不支持轻量识别。邮件容器MBOX保留前缀覆盖提示。扫描件OCR受预算与本地模型可用性限制。

此版本不将向量聚类或生成式命名作为导入必要依赖。目录区分度来自更好的内容提取、字段/标题相似性、业务与用途分组、项目和时间维度。需要真实业务数据评估语义分类质量；规则支持强度不是校准概率。

## 验证

`tests/test_isolated_portraits.py` 覆盖同格式业务区分、多格式解析、来源边界、稀疏大文件有界读取、暂停、补充预算、旧库迁移、分页、API归属、深度结果保留以及报告导出。

浏览器交互验证包括目录主题、来源展开、翻页、主题过滤和补充识别；无浏览器脚本异常。

规模测试使用100个1GiB稀疏文件验证逻辑总量100GiB时读取保持有界，不能等同于真实100GB扫描件吞吐。另使用10万条清单验证分页与目录响应。
