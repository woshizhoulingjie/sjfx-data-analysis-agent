# 大包问答索引：无变化同步优化（2026-09-26）

## 范围

仅优化 `LargeQAIndex.sync_store` 的重复同步。保留所有文件、摘要、向量、原文证据、权限判断和现有分词行为；不修改翻译、文件保护、邮件、界面和业务库结构。不更换模型，不降低文本质量门槛。

这不是增量变更日志：仍逐行读取并校验当前包全部索引输入，空间有界。只有完整输入一致才跳过摘要归一化、临时数据库写入和目录差异发布；不能用更新时间、文件数、抽样或不同SQLite连接的data_version代替。

## 正确性设计

- 指纹覆盖查询返回的全部字段、类型、长度、行顺序和embedding模型，包括同大小同时间的内容变化、删除、敏感标志、分组标签和向量。
- 在同一源读事务中读取模型及文件；完成扫描后释放源快照，再取得目标写锁并复核指纹。
- 若另一写入者改变目标指纹，重新开启源快照，执行正常同步。
- 指纹与文档在同一个目标事务中发布；失败时一起回滚。普通sync_rows调用会使缓存失效。
- 缓存绑定summary_generation、index_epoch和embedding_model。旧版回滚运行后即使遗留新元数据键，也会因目录版本变化而失效。原文解析单独更新generation，不会错误清空摘要缓存。
- 重启后可使用已验证的持久元数据；第一次升级仍进行完整同步以建立指纹。仅新增现有meta表内的键，不改变持久schema；旧版可忽略该键。
- running、queued及未知活跃状态不启用额外指纹扫描，继续原有单次完整同步；稳定包的版本或模型变化时跳过前置快速检查。时间戳仅用于决定不走快速路径，绝不用来证明数据相同。
- 源库始终只读。性能测试的目的索引独立创建并清理，不覆盖生产索引。

## 发布与回滚

每轮独立备份最新源码；发布前校验目标旧哈希，发布后校验新哈希。只重载问答索引后台，网页、普通分析、大包解析、翻译、保护和模型进程不主动重启。QA收到SIGTERM后完成当前处理并正常退出；超时不强杀，不继续覆盖源码。

回滚由该轮持久化release目录中的eng2_activate.py执行，只恢复本轮三个文件，拒绝覆盖后来编辑；不恢复旧业务数据库。新meta键可由旧版忽略，再次升级时版本绑定保护会强制必要重验。
